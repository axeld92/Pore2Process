# Scientific figures

The figures come from saved actual native data and an independent uniform Julia
boundary reference, using `python -m examples.adsorption.column_transport.plot`.
`outlet_verification.png` and `transport_failure.png` have been visually inspected.
They distinguish passing free-flow outlet controls from failed packed-bed
transport. `pumping_comparison.png` uses the selected actual Julia-to-DWSIM
cases and has also been visually inspected. It is a bed-friction duty at fixed
flow/inventory; it does not show qualified adsorption service. No new
browser/interface check is claimed.
