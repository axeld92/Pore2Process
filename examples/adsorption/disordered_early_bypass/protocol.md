# Early wall-free escape and the clean-film capture limit

Use the two already saved N160 tracer cohorts at 23.3 and 62.5 mL/min.
Retain the former split. The 8,192-marker group supplies the existing
sections 1–2 class sizes and reference arrivals in sections 3–8. The
separate 16,384-marker group supplies the wall operators. Keep ten
local transit-time ranks and four age ranks within each.

For a perfect first-contact sink, remove a marker on its first solid
wall hit. Report the absolute fraction of inlet dose arriving without
any wall contact. Compare three reductions using the same carrier
transitions: survival pooled by receiving state, survival by
donor–receiver pair with its inert local delay distribution, and a
joint wall-free delay distribution for each pair. Freeze the predictions
before scoring the independent first-passage curves at sections 3–8.
Use 2 percentage points for the maximum absolute cumulative error
including the eventual escape fraction and the first 10% and 25% of
the inert arrivals. Check 2 and 1 ms archive-coordinate time bins.

Form a 25 cm projection from 22 complete eight-section patterns and
four terminal sections, using the same fully mixed joins as the frozen
column model. Compose the direct held-out escape kernels independently
of the reduced kernels. Convert to physical time with the archived
column delay scaling. Report absolute escape by three nominal liquid
residence times and at the plateau. The projected bed is a synthetic
transfer of an eight-section holdout with a complete-mixing assumption.

If perfect first-contact capture permits a plateau below 5%, audit the
existing film model with the same mass, area, flow and the 50%-direct,
1%-reference-conductance case. Set all surface concentrations to zero
and keep the particles effectively unsaturable for this diagnostic.
Compare the saved wall-hit allocation with the best possible allocation
of the same total film conductance in the existing staged liquid balance.
Check both plateaus and the time to 5% when it is reached. If either
bed cannot meet 5% even at the best fixed-conductance limit, hold off
on a new adsorption run at these inputs. Read no experimental curves
for parameter selection.
