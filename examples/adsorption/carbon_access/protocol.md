# Isolated carbon versus slowly accessible carbon

Use the frozen N160 column with fully mixed repeat joins, the original
wall-contact shares, and the same 7.032455155 g dry mass and liquid volume.
Retain the spherical batch loading diffusivity, particle density, size,
Langmuir parameters and fluid film coefficient for each diameter.

Split the dry mass and geometric area in every section into the same
two proportions. Run a fully accessible control and two predeclared
direct-contact fractions, 50% and 75%, for both diameters. Distribute
each cohort's area among paths using the original wall-contact shares.
The direct cohort uses the original film. Compare three scenarios for
the other cohort: isolated, added access resistance with combined
conductance 1% of the direct film, and added access resistance with
combined conductance 10% of the direct film. These round factors span
a decade and are scenario inputs. Use the identical grid of fractions
and resistance ratios for both diameters.

The access resistance is in series with the unchanged external film.
For ratio r, the added per-area resistance is (1/r - 1)/kf. The isolated
case has zero transfer across the external barrier. Both cohorts retain
the same particle equation, and each has its own loading profile. Both
receive solute from the same liquid path concentrations at each section.
The extra barrier has negligible liquid storage in this scenario.
Thus the isolated cohort supplies no capacity, while any communicating
cohort can eventually equilibrate at the feed concentration. No carbon
is removed from the modeled bed.
