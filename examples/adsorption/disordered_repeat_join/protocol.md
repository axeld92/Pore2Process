Use the frozen fixed-carbon column case with its four age groups per
path, 80 µs probe inputs, wall-weighted contact, nine repeats for
0.80 mm and sixteen repeats for 0.45 mm. Keep 7.032455155 g dry
carbon for each size, the same liquid hold-up, and the same particle
kinetics, isotherm, film coefficient and area distribution. Include
every original section-rule and delay value.

Compare the existing fully mixed join with a join that routes each
of the 40 exit states to the inlet state of the same path and age rank.
Use the first-section delay distribution previously assigned to that
receiving state. Give the first repeat the original inlet. The
first-section rules have the same receiving flux fractions as the last
section has outgoing fractions, so each stream carries the same
throughput through the join. The rank-preserving join is a scenario
for persistence, with no claim of verified physical connectivity.

Compare the inert mean and variance of each full column to independently
propagated delay-network moments. Check the original inlet and all
marginal flow fractions, liquid hold-up, mass conservation and film
balance. Reproduce the archived mixed case. Evaluate both joins at
matched levels of time and radial refinement and use the existing
2% crossing and 0.005 curve-difference limits.

Freeze all predictions before reading the digitized Figure 7 markers.
Report the effect of preserving path memory on 5% and 50% crossings,
and score both joins with the existing experimental screens. Both
curves use published operating conditions and no Figure 7 fit.
